# CClip 验证范围

## 首次公开源码

2026-11-01，Windows 本地试用版本已由使用者确认通过验收。本次公开为经过清理的源码快照，不把本机开发历史、内部项目笔记、私人媒体、派生数据、配置或密钥推送到 GitHub。

此前 Windows 基线通过全量 14 组源码检查，以及实际免安装 EXE 的时间轴、字幕、封面、文件保存、隔离数据重开和真实本地转写验证。外部选片接口曾另行获准测试；本轮清理与公开准备不自动重放付费模型请求。

本轮新增目录清理说明和安全缓存清理。验收重点为：仅删除本程序登记的闲置临时文件，运行中的任务、未登记内容、文件系统链接、原片、工程、字幕、模型和成片均保留；切换生成目录后仍能处理以前登记的临时缓存。

公开准备阶段已运行 `scripts/quality_gate.py` 全部 14 组检查：后端 2377 项通过（另有 57 个子断言、2 项既有平台/外部网络跳过），前端 378 项通过，lint、类型和三个生产构建通过。Windows 最终解压 EXE 的新增功能检查 17 项通过：实际本地转写、5 秒成片导出、缓存清理、运行任务保护、数据保留与完整解码均有本机记录；本轮付费接口调用为零。

审查覆盖跟踪文件清单、代码静态检查、二进制来源、目录边界和将要公开的 Git 历史；保留上游的格式及类型写法待办，不以批量自动改写替代行为验证。已去掉路径管理中的不可达旧代码与输出状态的重复字段。公开快照与本轮产品代码逐件比较，工作区内部材料不进入公开历史。

审查时还在 Windows 重现了跨磁盘保存 ZIP 失败：系统临时目录在 C 盘、成片在其他盘时直接重命名会报错。压缩包临时文件现与输出使用同一磁盘，原视频不修改；回归覆盖 ZIP 内容、重复下载和已有文件保留。

另修复桌面本地保存接口遗漏成片 ZIP 路由的问题：修复前明确返回 422，修复后只放行对应本机成片的打包下载路径，仍不允许任意网址或文件路径。ZIP 进入所设置的下载目录，临时 ZIP 使用成片所在磁盘并在发送后删除。

源码检查结果、桌面实包验证和云端 CI 分别记录，不能相互替代。源码公开不创建正式 Release 或版本标签。

## 当前边界

- Windows x64 是已完成本地试用的平台。
- Intel Mac 与 Apple Silicon Mac 尚未完成原生安装包的真机验收；不能宣布三平台正式发布通过。
- 完整离线包解压约 1.54 GiB，未达到 500 MB 目标。
- 语音识别沿用原方案，准确率仍受音质、口音及术语影响，使用前需校对字幕。
- CClip 禁用上游的发版、PyPI 发布、反馈搬运和外部站点通知等自动化；只保留读权限的源码 CI、文档与 Windows 回归检查可在本仓库运行。上游发布门槛仍保留用于参考，不能绕过它们发布未经验证的产品。

## 可复现检查

使用 [开发说明](CCLIP_DEVELOPMENT.md) 安装依赖后运行全量检查。各测试采用隔离数据目录和合成素材；付费接口测试不在自动检查中。报告及二进制散列留在本机，公开只保留脱敏摘要。
