# CClip 使用与清理

当前仅支持 Windows x64 免安装版。从 [Releases](https://github.com/georgewithtaylor-dev/CClip/releases/tag/cclip-win-x64-preview-2026.11.02) 的 Assets 下载程序 ZIP；Source code (zip) 只是源码。

## 开始剪辑

完整解压免安装包后运行 `CClip.exe`；`resources` 是程序必需组件，不能单独删除其中的文件。首页左侧导入录播，右侧打开已保存项目。编辑中一个项目只使用一个原片。

手动选片可直接使用。AI 工作流需要自己的服务配置；“一键选片”顺序执行转写、选片、口语清理。原版语音模型保留，识别文字需要校对。AI 建议需要由使用者确认，自动标题不应替代内容审查。

原片时间轴显示完整录播，非 AI 区域也可加入。片段编号、颜色、来源与字幕勾选对应。字幕可逐行修改、搜索、定位、标记；成片编辑中的字幕也支持剪掉所选、仅保留所选。

常用操作：滚轮缩放时间轴，中键拖动，Shift 拖选范围；I/O 设置入点/出点，S 分割，Delete 删除，M 标记，Ctrl+Z 撤销。设置中的“剪辑与快捷键”可修改按键。

## 成片与封面

选中片段后进入“成片编辑”，调整视频范围、字幕、平台画幅和包装。画面与封面在同一设置区域，平台预设关联封面比例。切换本机模板或配色可预览，保存后再导出。

“自行生图”提供提示词与视频帧下载，可使用外部工具制作后上传封面。独立图像 API 需要自己的服务配置与费用；不提供 ChatGPT 订阅账号直接登录调用图像模型。

本版保留平台适配、本地文案和文件导出，不包含向社交账号投稿或定时发布。

## 文件在哪里，哪些能清理

打开 **设置 → 存储位置**。可直接输入磁盘完整路径或选择文件夹，点“应用并保存目录”。新任务使用新位置，旧文件不自动迁移；历史位置仍可打开。

| 位置 | 保存内容 | 清理方式 |
| --- | --- | --- |
| 生成成片目录 | 正式视频、字幕、兼容预览等 | 不整目录清空；确认不再需要后手动删除单个成片 |
| 下载/保存目录 | 下载的视频、封面、截图、提示词等，也可能混有其他文件 | 不整目录清空；自行管理 |
| 临时渲染缓存 | 本版创建并确认归属的任务中间文件 | 一键清理闲置缓存；正在运行、未知归属、文件链接会跳过 |
| 工程与设置目录 | 原片、工程、字幕、模型、配置及索引 | 保留；不可当作缓存删除 |
| 历史成片位置 | 旧输出，部分目录还包含工程或原片 | 打开后确认内容，手动管理 |

临时缓存通常在任务结束后自动清理。一键清理主要回收异常退出的残留；不会删除正式成片，未确认归属的旧版缓存也会保留。模型是重复使用的程序依赖，清理后会影响离线转写，所以不加入一键清理范围。

Windows 工程与设置默认为 `%APPDATA%/com.cclip.workbench`。下载完成的提示显示实际文件路径。移动程序文件夹不会自动移动项目。

## 隐私

本地剪辑、本地转写不需要上传原片。选择云端分析或图像服务时，先核对界面中的服务地址、发送内容和额度消耗，再决定是否继续。不要将密钥、Cookie、私人原片或字幕放到公开 Issue。
