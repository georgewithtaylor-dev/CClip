# CClip

**Découpage de captations et montage par sous-titres**

[简体中文](README.md) · [English](README-EN.md) · [日本語](README-JA.md) · [한국어](README-KO.md) · [Español](README-ES.md) · [Português](README-PT.md) · [Русский](README-RU.md) · [Français](README-FR.md)

Basé sur AutoClip : timeline complète, sous-titres modifiables, sélection manuelle ou IA, forme d’onde, annulation, couvertures locales et préréglages par plateforme.

Le portable Windows x64 a passé la recette locale. Cette première publication de sources ne contient pas de binaires. Intel Mac et Apple Silicon restent à valider. Le paquet complet extrait pèse environ1.54 GiB ; l’objectif de500 MB n’est pas atteint.

Extrayez tout le ZIP et lancez CClip/CClip.exe en gardant resources à côté. L’IA utilise votre quota API. Réglages → Stockage permet de changer les dossiers et d’effacer les temporaires inactifs vérifiés. Projets, sources, sous-titres, modèles et vidéos finales sont conservés.

Une source par projet. Aucune publication de compte ni programmation. Les services cloud reçoivent les données décrites dans le consentement. Aucun accès direct au compte ChatGPT pour générer des images.
