# CClip

**Recortes de gravações e edição por legendas**

[简体中文](README.md) · [English](README-EN.md) · [日本語](README-JA.md) · [한국어](README-KO.md) · [Español](README-ES.md) · [Português](README-PT.md) · [Русский](README-RU.md) · [Français](README-FR.md)

Baseado no AutoClip: linha do tempo completa, legendas editáveis, recortes manuais ou por IA, forma de onda, desfazer, capas locais e predefinições por plataforma.

**[Baixar ZIP portátil para Windows x64](https://github.com/georgewithtaylor-dev/CClip/releases/download/cclip-win-x64-preview-2026.11.02/CClip-Windows-x64-portable.zip)** · [Release](https://github.com/georgewithtaylor-dev/CClip/releases/tag/cclip-win-x64-preview-2026.11.02)

Suporte atual: **somente Windows x64 portátil**. Baixe o ZIP do aplicativo em Releases; Source code (zip), gerado automaticamente, não é o programa. Esta versão não oferece suporte a macOS nem Windows ARM64. O pacote extraído ocupa cerca de 1.54 GiB; a meta de 500 MB ainda não foi atingida.

Extraia todo o ZIP e execute CClip/CClip.exe mantendo resources ao lado. A IA usa sua própria cota API. Configurações → Armazenamento permite mudar pastas e limpar temporários inativos verificados. Projetos, originais, legendas, modelos e vídeos finais são preservados.

Um original por projeto. Sem publicação em contas ou agendamento. Serviços em nuvem recebem os dados informados no consentimento. Não há login direto na conta ChatGPT para gerar imagens.
