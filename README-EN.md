# CClip

**Local recording clips and transcript-driven editing**

[简体中文](README.md) · [English](README-EN.md) · [日本語](README-JA.md) · [한국어](README-KO.md) · [Español](README-ES.md) · [Português](README-PT.md) · [Русский](README-RU.md) · [Français](README-FR.md)

CClip builds on AutoClip with a full-source timeline, editable captions, manual and AI-selected clips, waveform editing, undo, local covers and platform output presets.

Windows x64 portable builds passed local user acceptance. This first public source snapshot includes no release binaries. Intel and Apple Silicon Mac acceptance is pending. The full offline bundle extracts to about 1.54 GiB, above the 500 MB goal.

Extract the whole ZIP and run CClip/CClip.exe. Keep resources beside it. Configure AI services with your own API quota. Settings → Storage lets you change output/save locations and clear verified inactive scratch files. Projects, sources, captions, models and finished videos are retained.

One source per project. No account posting or scheduled publishing. Local operations stay on the computer; cloud operations send the data described in the consent dialog. No direct ChatGPT account image-generation login is provided.
