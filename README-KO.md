AutoClip을 바탕으로 전체 원본 타임라인, 자막 편집, 수동·AI 클립, 파형, 실행 취소, 로컬 표지와 플랫폼별 출력 설정을 제공합니다.

**[Windows x64 포터블 ZIP 다운로드](https://github.com/georgewithtaylor-dev/CClip/releases/download/cclip-win-x64-preview-2026.11.02/CClip-Windows-x64-portable.zip)** · [Release](https://github.com/georgewithtaylor-dev/CClip/releases/tag/cclip-win-x64-preview-2026.11.02)

현재 지원: **Windows x64 포터블 버전만**. Releases에서 프로그램 ZIP을 받으세요. 자동 생성되는 Source code (zip)은 실행 패키지가 아닙니다. 이 버전은 macOS 및 Windows ARM64를 지원하지 않습니다. 전체 오프라인 패키지는 압축 해제 후 약 1.54 GiB이며 500 MB 목표는 미달입니다.

ZIP 전체를 풀고 CClip/CClip.exe를 실행하며 resources를 보관하세요. AI에는 본인의 API 사용량이 필요합니다. 설정의 저장 위치에서 출력 폴더를 바꾸고 확인된 유휴 임시 파일을 정리할 수 있습니다. 프로젝트·원본·자막·모델·완성 영상은 보관합니다.

프로젝트당 원본 하나를 처리합니다. 계정 게시·예약 게시는 제공하지 않습니다. 클라우드 작업은 동의 화면의 데이터를 전송합니다. ChatGPT 계정 로그인으로 이미지를 생성하는 기능은 없습니다.
