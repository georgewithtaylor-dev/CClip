# CClip

**Нарезка записей и монтаж по субтитрам**

[简体中文](README.md) · [English](README-EN.md) · [日本語](README-JA.md) · [한국어](README-KO.md) · [Español](README-ES.md) · [Português](README-PT.md) · [Русский](README-RU.md) · [Français](README-FR.md)

На основе AutoClip: полная шкала исходника, редактируемые субтитры, ручная и ИИ-нарезка, звуковая волна, отмена, локальные обложки и настройки платформ.

Портативная версия Windows x64 прошла локальную приёмку. Первый публичный снимок исходников не содержит бинарных выпусков. Intel Mac и Apple Silicon ещё не проверены. Полный пакет после распаковки занимает около1.54 GiB; цель500 MB не достигнута.

Распакуйте весь ZIP и запустите CClip/CClip.exe, сохранив папку resources рядом. ИИ использует вашу квоту API. В настройках хранилища можно менять папки и очищать проверенные неактивные временные файлы. Проекты, исходники, субтитры, модели и готовые видео сохраняются.

Один исходник на проект. Нет публикации в аккаунтах или по расписанию. Облачным службам передаются данные, указанные в запросе согласия. Прямого входа в ChatGPT для генерации изображений нет.
